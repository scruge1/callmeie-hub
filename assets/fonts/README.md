# CallMeIE house fonts

These are the existing Archivo Black and IBM Plex Sans font files used by the
Great National pilot proposal pack. Source: the maintained GN meeting workspace,
assets/fonts. Their accompanying OFL licence files are retained here.

Archivo Black supplies display headings. IBM Plex Sans supplies body text,
navigation, labels and numeric data. This keeps two common-site font families.
Distinct demo websites retain their own type systems. No new font dependency or
remote font request is required for the common site.
